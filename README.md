# Grocery Store Checklist

A command-line application for managing a grocery list with price tracking, data persistence, and automated testing.

## Features
- Add, remove, and view grocery items
- Track quantity and price per item
- Calculate total estimated cost
- Mark items as purchased
- **Data Persistence:** Automatically saves and loads data from JSON files
- **Automated Testing:** Includes pytest test suite for core functionality
